## Технические требования

1. **OpenLayers напрямую** (`import Map from 'ol/Map'` и т.п.), без обёрток и без Leaflet (рулсет §E).
2. Проекция карты — `EPSG:3857` (по умолчанию), координаты центра и полигона задаются в градусах
   и переводятся через `fromLonLat` из `ol/proj`. Порядок координат OL — `[долгота, широта]`.
3. Контракт (точные сигнатуры):

```ts
// layers.ts
/** Кольцо полигона зоны для OL: координаты [lon, lat], кольцо замкнуто, проекция карты EPSG:3857. */
export function zoneFeature(zone: ServiceZone): Feature<Polygon>;

/** Слой зоны обслуживания: заливка и контур берутся из токенов темы. */
export function createZoneLayer(zone: ServiceZone): VectorLayer<VectorSource<Feature<Polygon>>>;

/** Слой подложки из реестра BASEMAPS (по умолчанию — первый элемент реестра). */
export function createBasemapLayer(basemap?: Basemap): TileLayer<TileSource>;

// create-map.ts
/** Представление карты: центр Бишкека из MAP_CENTER, зум MAP_ZOOM, ограничения зума по подложке. */
export function createMapView(): View;

/** Карта без React: три слоя в порядке «подложка → зона», привязка к элементу. */
export function createParkMap(target: HTMLElement): Map;
```

4. **Цвета только из темы**: слой зоны обязан брать цвета через `readZoneColors()`
   (`--zone-stroke`, `--zone-fill` из `global.css`). Никаких hex-констант и названий цветов в коде.
5. Зона рисуется **под** будущими маркерами: у слоя зоны `zIndex` меньше, чем будет у парка
   (поставь `zIndex: 10` для зоны; подложка — без zIndex).
6. Карта не должна «улетать»: ограничения по зуму берутся из подложки (`maxZoom`), минимальный зум — 10.
7. Никаких обращений к сети, таймеров и подписок на события карты в этих файлах.
8. Комментарии — по делу, объясняют «почему» (например, зачем `fromLonLat`), без пересказа кода.

## Обязательные тесты (минимум 9)

Тесты не должны создавать полноценную карту в jsdom: проверяются чистые фабрики и геометрия.

1. `zoneFeature` возвращает ровно один полигон.
2. Кольцо замкнуто: первая координата равна последней.
3. Число вершин кольца = число точек зоны + 1.
4. Координаты переведены в EPSG:3857 (значения порядка 8 000 000 по X, а не 74), проверь через
   `toLonLat` обратное преобразование: первая точка ≈ `ZONE.coordinates[0]` с точностью 1e-6.
5. Повторный вызов `zoneFeature` не мутирует исходную зону (проверь, что `ZONE.coordinates` не изменился).
6. `createZoneLayer` возвращает слой с одним объектом (`getSource()?.getFeatures()` длина 1),
   `zIndex === 10`.
7. Цвета слоя зоны совпадают с темой: в тесте выставь переменные
   (`document.documentElement.style.setProperty('--zone-stroke', '#123456')` и `--zone-fill`),
   затем проверь, что стиль заливки/контура содержит эти значения
   (`style.getFill()?.getColor()`, `style.getStroke()?.getColor()` через `getStyle()` слоя —
   стиль верни функцией или `Style`-объектом, главное, чтобы эти методы были доступны).
8. `createBasemapLayer` без аргумента использует первую подложку реестра: в источнике URL содержит
   тот же шаблон, что `BASEMAPS[0].url`.
9. `createMapView` даёт центр, равный `fromLonLat(MAP_CENTER)`, зум `MAP_ZOOM`, `minZoom` 10 и
   `maxZoom` равный `maxZoom` подложки по умолчанию.
