# transport-sharing — сервис шеринга самокатов

Учебный/тестовый проект: клиент-серверный сервис шеринга электросамокатов.
Пользователь находит свободный самокат на карте, бронирует его, едет и платит по факту.

**Стек:** React 19 + Vite 8 + TypeScript + Tailwind 4 + OpenLayers (фронт) ·
Node.js 22 + Fastify 5 + pg + ws (бэкенд) · PostgreSQL 17 · Docker Compose (3 контейнера).

## Быстрый старт

```bash
docker compose up -d --build   # три контейнера: база, бэкенд, фронт → http://localhost:8088
```

Схема и данные применяются автоматически (одноразовые сервисы `db-migrate` и `db-seed`).
Демонстрационный доступ (пароль у всех — `demo1234`):
`demo@sharing.kg` — с историей поездок и счетами; `demo2@sharing.kg` — второй вход с теми же правами
без истории (удобно, когда нужно два браузера: например, посмотреть, как один клиент видит бронь
другого); `alan@example.com`, `bora@example.com`, `dina@example.com`, `erik@example.com`,
`fiza@example.com` — остальные пользователи с данными.

Проверить всё снаружи, как браузер: `bash scripts/demo.sh` — поднимет стек и прогонит сценарии
(состояние парка, поток событий, два клиента одновременно), печатая результат каждого шага.

Два режима источника данных у интерфейса: `VITE_API_MODE=http` (по умолчанию в контейнере) — данные
с сервера, общие для всех клиентов; `mock` — мок-файлы и «сервер» в памяти вкладки, чтобы посмотреть
интерфейс без базы. Dev-режим без Docker — в [`docs/RUNBOOK.md`](docs/RUNBOOK.md).

## Структура

```
shared/    доменный контракт: типы, zod-схемы, тарифы, деньги, время, зона, ws-протокол, симулятор
frontend/  React SPA: карта парка, бронь, поездка, кабинет, счета, эмуляция почты
           два источника данных за одним интерфейсом (моки и сервер), сборка в nginx-образ
backend/   Fastify: REST + WebSocket-хаб, симулятор парка, миграции SQL, сид из mock/
mock/      сид-данные JSON — источник для БД и для режима моков в интерфейсе
prompts/   задания, отданные AI-воркеру (требование сдачи промптов)
metrics/   учёт экономии локального инференса (токены воркеров, параллельность, деньги по ценам DeepSeek)
scripts/   служебные скрипты (сбор статистики, проверки, demo.sh — сценарий приёмки)
docs/      план, архитектура, рулсет, ADR, приёмка, evidence
```
