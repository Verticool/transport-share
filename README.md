# transport-sharing — сервис шеринга самокатов

Учебный/тестовый проект: клиент-серверный сервис шеринга электросамокатов.
Пользователь находит свободный самокат на карте, бронирует его, едет и платит по факту.

**Стек:** React 19 + Vite 8 + TypeScript + Tailwind 4 + OpenLayers (фронт) ·
Node.js 22 + Fastify 5 + pg + ws (бэкенд) · PostgreSQL 17 · Docker Compose (3 контейнера).

## Быстрый старт

```bash
cp .env.example .env
docker compose up --build     # фронт на http://localhost:8088
```

Dev-режим без Docker, и режим «фронт без сервера на мок-данных» — в [`docs/RUNBOOK.md`](docs/RUNBOOK.md).

## Структура

```
shared/    доменный контракт: типы, zod-схемы, тарифы, деньги, время, зона, ws-протокол, симулятор
frontend/  React SPA: карта парка, бронь, поездка, кабинет, счета, эмуляция почты
backend/   Fastify: REST + WebSocket-хаб, симулятор парка, миграции SQL, сид из mock/
mock/      сид-данные JSON — общий источник для фронта (стадии S2–S7) и БД (S8+)
prompts/   задания, отданные локальному AI-воркеру (требование сдачи промптов)
metrics/   учёт экономии локального инференса (токены воркеров, параллельность, деньги по ценам DeepSeek)
scripts/   служебные скрипты (сбор статистики, проверки)
docs/      план, архитектура, рулсет, ADR, приёмка, evidence
```
