## Не делаем сознательно (и почему)

| Что | Почему |
|---|---|
| Реальная оплата, платёжный провайдер | Вне рамок задания: счёт формируется, оплата эмулируется |
| Настоящий SMTP/push | ТЗ №10 прямо разрешает заглушки; почта — таблица + экран «Входящие» |
| Всё, что в запретном списке `RULES.md §E.2` (Redis, очереди, k8s, микросервисы, ORM, Vue, Leaflet, MSW, Jest и т.д.) | Проект локальный и стадиальный; стек заморожен закрытым списком §E.1, расширяется только через ADR |
| PostGIS, гео-роутинг по дорогам | Симулятор движения достаточен; полигон проверяется ray casting |
| Мобильные приложения, PWA, i18n | Не в требованиях |

## Известные ограничения

- Парк — 40 самокатов в одном городе (Бишкек); масштабирование на город не проверялось.
- Симулятор «водит» самокаты линейно (без учёта улиц), скорость и шум GPS — константы.
- Один инстанс бэкенда: масштабирование ws-хаба на несколько процессов не рассматривается.
- Тайминги брони проверяются с подменой часов; реальные 15 минут в e2e прогоняются в отдельном
  длинном сценарии (помечается в evidence отдельно).
- До S11 источник данных фронта — мок-данные: состояние «сервера» живёт в памяти вкладки, поэтому
  обновление страницы теряет созданные в сессии бронь/поездку/счёт (сессия сохраняется). С S11 это
  не ограничение продукта: с `VITE_API_MODE=http` состояние живёт в PostgreSQL и переживает
  перезагрузку страницы и перезапуск браузера. Мок-режим остаётся вторым режимом — для быстрого
  показа интерфейса без базы.
- Сборка фронта — один чанк 755 КБ (gzip 228 КБ) из-за OpenLayers; код-сплиттинг не делали
  осознанно (локальный запуск и docker-образ от этого не страдают), см. ADR-007.

## Правки после сдачи (14.10.2026)

| Что | Было | Стало |
|---|---|---|
| Выбор самоката на карте | забронировать можно было только из списка справа | клик по маркеру открывает ту же карточку с бронью; курсор над точкой — указатель, выбранный маркер выделен кольцом (`evidence/fixes/map-click-and-test-db.txt`) |
| Пауза под вторым демо-входом | «пользователь не найден», самокат оставался «в поездке» | причина была не в коде: интеграционные тесты запускались против рабочей базы и стирали сессии и незакрытые поездки. Теперь у проверок своя база `sharing_test` |
| Демо-данные | 5 самокатов «в поездке» без открытой поездки — выглядело как занятый «неизвестно кем» самокат | у каждого такого самоката есть открытая поездка конкретного пользователя; демо-входы (`demo@`, `demo2@`) свободны — с них начинаются сценарии приёмки |
| nginx после пересборки бэкенда | 502 до перезапуска nginx (адрес контейнера менялся) | имя резолвится через DNS Docker (`resolver 127.0.0.11`), фронт переживает пересборку бэкенда |

| Подзум карты во время поездки | вид переводился на каждое обновление самоката (раз в секунду), отзумиться было нельзя | вид подводится только после 6 с без действий с картой и не чаще раза в 4 с — можно спокойно смотреть город |
| Фильтр состояний | «только свободные» — единственный вариант | сводка парка стала фильтром: любое сочетание состояний и на карте, и в списке; кнопка возвращает все |
| Самокат вне зоны | поездку закрывал сервис (причина `service`) — клиент не платил за время возврата | мотор блокируется, поездка и время идут, самокат везут обратно: `POST /api/rides/:id/push-to-zone`; в демо-данных есть такой самокат (SC-030) |
| Второй самокат во время поездки | кнопка просто серая, причина непонятна | сказано словами, к какому самокату вернуться; вторая поездка или бронь не поддерживаются сервером (частичные индексы) |
| Одновременные действия двух клиентов | проверялось только распространение событий | отдельный e2e: оба бронируют один самокат одновременно — бронь достаётся ровно одному |
| Заряд в поездке | заряд самоката был виден только в списке парка | заряд показан в шапке панели поездки и обновляется вместе с парком |
| Ручки проверки | автофиниш по разряду и оповещения о снятии брони приходилось ждать десятки минут | в джойстик добавлен переключатель шага 20/200 м и кнопка «−10 % заряда», в панель брони — «−1 мин»/«−12 мин»; разряд до нуля закрывает поездку как симулятор |
| История и счета | список «Поездки» считал минуты своим округлением, счёт — тарифицируемыми минутами домена: по одной поездке выходило «2 мин» против «3 мин»; в истории показывалось начало поездки, в счёте — момент выставления | минуты считает домен и отдаёт их в `/api/rides`; в истории видно период и «Езда N мин · пауза M мин», в счёте подписано «Счёт от …» |
| Низкий заряд | предупреждения не было: человек узнавал о разряде по факту отключения самоката | при заряде ниже 20 % в панели поездки появляется предупреждение и подсказка с ближайшим свободным самокатом; в карточке — предупреждение до брони |
| Запуск и настройки | значения (порты, креды базы, секрет, шаги симулятора) были захардкожены в compose, а `.env.example` описывал переменные, которых код не читает; локального запуска «с нуля» в отчётах не было | всё вынесено в закоммиченный `.env` с рабочими дефолтами, compose подставляет значения и собирает строку подключения в одном месте; холодный старт (`down -v` → `up -d --build`) проверен: миграции и сид отрабатывают, в базе все статусы и учётки |
| Выезд из зоны | о блокировке мотора сообщала только панель поездки: при взгляде на карту выезд можно было не заметить, а время тарифицировалось | полоса под хедером «Вы выехали из зоны обслуживания» + всплывающее оповещение (одно на выезд) и сообщение о разблокировке при возврате |
| Оповещения: вид и «застревание» | фоны были полупрозрачными (и часть классов ссылалась на несуществующий токен), а предупреждение о заряде висело в карточке недоступного самоката с текстом «поездка будет короткой» | непрозрачные поверхности-токены в обеих темах; предупреждение о заряде — только для самоката, который можно взять, и только пока поездка активна; при нуле текст про разряд |
| Сортировка парка | список не сортировался, а карточка «Парк» сжималась до высоты колонки — таблица выходила за фон (замер: карточка 492 px, список 1360 px) | сортировка по клику на колонку (доступность, заряд, «до центра») с переворотом порядка; карточка растёт по содержимому, прокрутка одна — у колонки панелей |
| Оповещения | предупреждения жили внутри панелей: при фокусе на карте их не видно, о разряде и автофинише узнавали из почты; о потере сети не сообщалось | постоянные состояния — полосой под хедером, события — всплывающими поверх экрана с автоскрытием; состояние сети меняет полосу на «доступ восстановлен»; звук с переключателем |
| Таблица парка на телефоне | список обрезался до трёх строк (163 px при сорока самокатах), а подсветка строки выступала за внутренние поля карточки из-за отрицательных отступов | карта — верхняя треть, список растёт по содержимому и прокручивается одной прокруткой; отрицательные отступы только на широком экране |
| Вёрстка на телефоне | хедер не влезал (кнопка входа уезжала за экран), карта занимала меньше половины, панель прокручивалась целиком, шапка колонок переносилась на три строки, кнопка разряда уходила под нижний край | хедер сжимается и прокручивается, на узком экране пункты — иконками; карта получает верхние 45 % высоты, панель скроллится сама; строки парка и шапка — одна сетка; разряд переехал в строку заголовка |
| Скролл списка парка | подвод строки через `scrollIntoView` прокручивал и колонку панелей: панель поездки с управлением уезжала за верхний край | прокручивается только список (`scrollTop`), при появлении поездки колонка поднимается к началу |
| Истечение брони | снятая по сроку бронь не объявлялась в потоке (самокат не двигается — дельты о нём нет), а интерфейс спрашивал о броне ровно один раз: панель висела, самокат оставался занятым | освобождение объявляется событием парка, а интерфейс повторяет запрос, пока бронь не снята |
| Пауза | самокат на паузе продолжал ехать и тратить заряд | пауза — выключенный мотор: движение и расход заряда только у идущей поездки, руль на паузе отклоняется |
| Граница зоны | мотор считался выключенным за границей, а шум GPS прижимал самокат к полигону — состояние «вне зоны» было неуловимым | мотор за границей работает, завершить поездку нельзя (422), шум GPS не прижимает самокат назад, цель движения за границей — наружу |
| Руль для проверки | выехать за зону и вернуться было нечем | в панели поездки появилось управление: 20 м за нажатие, четыре стороны света (`POST /api/rides/:id/steer`) |
| Письма и счёт | письмо со счётом не проверялось через интерфейс | live e2e: после поездки письмо со счётом есть во «Входящих», повторное завершение не создаёт второго письма |
| Список парка и выбор | выбранная строка могла быть за пределами вида (список отсортирован по удалённости и прокручивается), а отфильтрованный список читался как «самокаты пропали» | список подводится к выбранному самокату; при снятых состояниях панель пишет «Показано N из 40» |
| Клик по маркеру | при близко стоящих самокатах открывался соседний: OpenLayers отдавал первый объект в радиусе 8 px | выбирается ближайший к точке клика маркер |

| Клик по пустому месту карты | выделение оставалось на прежнем самокате | клик по свободному месту снимает выделение; панорамирование карты (клик + драг) выделение сохраняет; во время поездки карта выделение не сбрасывает |
