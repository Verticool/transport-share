  клиент alan@example.com: вход 200

Шаг 2. Первый клиент бронирует свободный самокат
  demo@sharing.kg → SC-001: 201
  состояние самоката для наблюдателя: reserved

Шаг 3. Второй клиент пытается забронировать тот же самокат
  alan@example.com → SC-001: 409 conflict «Этот самокат сейчас недоступен»

Шаг 4. Второй клиент бронирует другой самокат — это разрешено
  alan@example.com → SC-002: 201

Шаг 5. Первый клиент снимает бронь — самокат снова свободен для всех
  отмена: 204, состояние самоката: free

Итог: два клиента работают одновременно, чужую бронь перехватить нельзя,
состояние парка общее. Второй клиент держит свою бронь: ed350356…
