# BRAND.md — название, тон и терминология

Единый источник для текстов интерфейса, писем и ошибок. Меняем здесь, а не по месту в компонентах.

## Название

| | |
|---|---|
| Имя | **Движ** |
| Латиница | `dvizh` (для логотипа, домена `dvizh.kg`, e-mail) |
| Слоган | «Самокаты Бишкека» |
| Как склоняем | «В Движе», «приложение Движа» — как обычное существительное |
| Чего не делаем | не пишем «ДВИЖ.kg», «Движ Сервис», «Dvizh Sharing» — ни канцелярита, ни кальки |

Почему так: четыре буквы садятся и в хедер, и в логотип; смысл — движение и поездки, а не абстрактный
«шеринг»; читается по-русски без перевода и без транслитерации; не путается с Whoosh, Яндекс Go, Urent.

Логотип (черновое решение, финализируется на S3): словесный знак строчными — `движ` + точка цвета
основного действия (`движ.`). Отдельная иконка-монограмма не нужна, пока не появится потребность
в favicon маленького размера — там используем `д`.

## Тон общения

- Дружелюбно, коротко, по делу. Без канцелярита («осуществляется», «в случае необходимости»)
  и без панибратства.
- Обращение — на «вы», но без официоза: «Самокат свободен», «Бронь истекает через 3 минуты».
- Числа пишем цифрами, деньги — с валютой и двумя знаками: `31.00 сом`.
- Время — как в приложении: `12:34`, длительность — `4 мин 20 с`.
- Никаких восклицательных знаков в ошибках и оплате. Восклицательный знак допустим только
  в подтверждениях действия («Поехали!») — и не более одного на экран.

## Терминология (используем дословно)

| Что | Как называем | Чего не используем |
|---|---|---|
| Единица транспорта | **самокат** | «скутер», «транспортное средство», «unit» |
| Активная поездка | **поездка** | «сессия», «рейд», «trip» |
| Удержание до старта | **бронь** | «резерв», «букинг» | 
| Остановка в пути | **пауза** | «стоп», «холд» |
| Конец поездки | **завершить поездку** | «закрыть», «финишировать» |
| Область работы сервиса | **зона обслуживания** | «геозона», «полигон» |
| Уровень заряда | **заряд** (в процентах) | «батарея», «топливо» |
| Документ об оплате | **счёт** | «инвойс», «чек», «квитанция» |
| Эмуляция почты | **Входящие** | «мейлер», «SMTP-лог» |
| Личный раздел | **Кабинет** | «профиль» (профиль — только форма редактирования данных) |

## Статусы самоката в интерфейсе

| Код в API | Текст в UI | Как показываем |
|---|---|---|
| `free` | Свободен | зелёный маркер, доступен для брони |
| `reserved` | Забронирован | синий маркер; если бронь ваша — «Ваша бронь» |
| `in_ride` | В поездке | оранжевый маркер, недоступен для брони |
| `unavailable` | Недоступен | серый маркер; в карточке причина: «низкий заряд» / «на обслуживании» |

## Тексты, которые уже известны (шаблоны)

| Событие | Текст |
|---|---|
| Бронь создана | «Самокат {code} ваш. Поезжайте, пока не истекли 15 минут.» |
| Напоминание за 3 минуты | «Бронь снимется через 3 минуты — начните поездку или продлите её в кабинете.» |
| Бронь истекла | «Бронь снята, самокат {code} снова свободен.» |
| Финиш вне зоны | «Здесь завершить поездку нельзя — вернитесь в зону обслуживания.» |
| Заряд кончился | «Самокат разрядился, поездка завершена автоматически. Счёт за {minutes} мин — {amount}.» |
| Счёт готов | Тема письма: «Счёт за поездку {code}»; тело: минуты езды, минуты паузы, разбивка суммы. |
| Нет связи | «Похоже, пропала связь. Поездка продолжается, счёт идёт — данные обновим, когда вернётесь.» |
| Второй бронирует тот же самокат | «Самокат только что забронировали. Выберите другой — свободные рядом.» |

## Что НЕ делаем в текстах

- Не обещаем того, чего нет: никаких «оплата картой» и «поддержка 24/7», пока их нет в коде.
- Не показываем технические коды (`409 scooter_not_free`) — только текст, код остаётся в логах и в API.
- Не используем английские слова там, где есть русские (кроме «GPS» и общепринятых).
