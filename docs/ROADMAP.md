# ROADMAP.md — стадии разработки (референс и контроль)

Правило: стадия закрыта только когда её «Критерий приёмки» выполнен **сырым выводом команды**
(тест/скрипт/замер), записанным в `docs/evidence/S<номер>/`. Не «сделано», а «проверено чем».
Порядок стадий обязателен: фронт закрывается полностью на моках, потом сервер, потом БД-инстанцией.

К критериям приёмки каждой стадии добавляется проверка типизации и валидации из `RULES.md §F.6`:
`tsc --noEmit` exit 0, `eslint` 0 ошибок, grep на касты/`@ts-*` — пусто.

Легенда исполнителя: **О** — оркестратор (я), **В** — локальный воркер (сабагент на kat-coder).

снятие брони тоже доходит, обрыв связи не ломает экран и поток восстанавливается сам.
Автоснятие по сроку проверяется на сервере (`tests/db/api.test.ts`, подмена времени инъекцией
`Clock`) — в браузерном тесте время не подменить, поэтому там проверено распространение состояния.
